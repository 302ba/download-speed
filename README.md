# Измерение скорости скачивания на Node.js

Скрипт выполняет **10 последовательных HTTP(S) GET-запросов** к указанному URL. Каждый следующий запрос начинается только после того, как полностью получено тело предыдущего ответа. Сторонние зависимости не нужны.

## Требования

- Node.js 20 или новее.

## Запуск

```bash
node bench.mjs "https://ichef.bbci.co.uk/ace/standard/480/cpsprodpb/b1d9/live/7c2f9f00-df41-11f1-a48c-75dd2efdacb5.jpg.webp"
```

URL передаётся первым аргументом командной строки. Поддерживаются адреса `http://` и `https://`. HTTP-перенаправления обрабатываются стандартным `fetch`.

## Результат

Для каждого запроса выводятся время и количество полученных данных. После десятого запроса выводятся:

- **Среднее время запроса**
- **Общий объём скачанных данных**
- **Средняя скорость скачивания**

Пример формата вывода (числа условные):

```text
#1: HTTP 200 | 209.3 ms | 11.13 KB
...
#9: HTTP 200 | 198.1 ms | 11.13 KB
#10: HTTP 200 | 196.3 ms | 11.13 KB

--- Results ---
Successful requests : 10/10
Average request time: 259.9 ms
Total downloaded    : 111.25 KB
Download speed      : 42.80 KB/s (0.35 Mbit/s)
```
